
# ForgeOS AI

Elite AI Life Operating System

## Modules
- ForgeOS Fitness
- ForgeOS Drive
- ForgeOS DevOps
- ForgeOS Focus

## Stack
- Next.js 14
- Tailwind CSS
- Framer Motion
- AWS Lambda
- API Gateway
- Bedrock Claude
- AWS SAM

## Deploy Backend
cd forgeos-ai-infra
sam build
sam deploy --guided

## Deploy Frontend
cd forgeos-ai-frontend
npm install
npm run dev
